Quod 0.3.2: the reference now tells an agent to keep its helpers private. Neither the verifier nor the generated code changes: only the text of the reference, which agents read through `quod_reference`.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first. The MCP server:
`claude mcp add quod -- /path/to/quod mcp`, or see
[docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md). `Quod.Build`, attached, is a NuGet package:
see [its README](https://github.com/quod-lang/quod/blob/main/packaging/Quod.Build/README.md).

## Changed

- **The reference recommends `private fn` for helpers.** What is public is the API of the generated code, and in C# a helper over `int` shows a `BigInteger` there.

## Measured

- [T9](https://github.com/quod-lang/quod/blob/main/bench/runs/t9-billing/report.md), a billing engine of about 300 lines over three modules, written by Haiku and Sonnet from a specification on 0.3.1: 12 of 12 verified and pass a separate oracle on 436 orders, 6 of 6 on 235 orders in C# on .NET Framework 4.7.2. `i64` costs failed proofs (38 against 7 with `int`), and not money.
- [T10](https://github.com/quod-lang/quod/blob/main/bench/runs/t10-proportional/report.md), the same with a discount shared in proportion, a product of variables: 12 of 12 again. **The ceiling was not reached.** The rules, the oracle, the tests and the compiler have one author, and one product is not a hard case.
- [T11](https://github.com/quod-lang/quod/blob/main/bench/runs/t11-private/report.md), on this version: all 6 runs made helpers private, against none of 6 before. Public methods with a `BigInteger` fall from 19 to 30 down to 0 to 17, and nothing else moved.
- All compiler tests pass. The mutant benches were not rerun: neither the verifier nor the generated code changes.

## Known

Those of [0.3.1](https://github.com/quod-lang/quod/releases/tag/v0.3.1).

- A helper called from another module must stay public: Quod has no visibility in between. The `BigInteger` of hidden helpers leave the API, not the generated code.
