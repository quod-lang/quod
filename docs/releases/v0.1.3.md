Quod 0.1.3: what a test of 0.1.2 found, and stronger measurements.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first. The MCP server:
`claude mcp add quod -- /path/to/quod mcp`, or see
[docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md).

## Fixed

- **A hard obligation costs one time limit, and the budget is kept.** A true obligation out of
  z3's reach cost twice the time limit plus a second (31 s with `--timeout 10`), and a budget of
  15 s answered at 21 s. An obligation about integers and booleans only now goes to the
  arithmetic process alone; any other gets a second try only after a quick "unknown", never after
  a timeout, within what is left of the budget. The same obligation now takes 10.4 s, and 10.3 s
  with a budget of 15 s.
- **Progress during a long check.** All the notifications arrived with the answer. Each function
  and each completeness check is now told when it starts and when it ends, and a solver try still
  running after a second is told once (`f0: postcondition (ensures #1), solver, up to 7 s`).
  Progress grows at each notification.
- **The solver's counterexamples are run.** A model of a negated obligation is run on the
  function. If the same obligation breaks, the diagnostic is `refuted` with evidence `run` and
  the inputs: a certain bug. If nothing breaks, the model is a state the code never reaches,
  usually allowed by an invariant too weak to prove the obligation: the diagnostic is
  `inconclusive` with evidence `unconfirmed`, and says so.
- **Syntax errors say what to write** for the habits of a model that knows Dafny: contract
  clauses inside the body, `;` after a clause, `for`, `let result`, `return` in an ensures.

## Measured

- Mutant bench: 57 of 64 mutants refuted, none unconfirmed or without a hint, the 7 survivors
  equivalent; quantified.quod 28 of 29. No verdict changed from 0.1.2.
- VerifBench, three trials of six tasks with Haiku: 18/18 accepted through the shell, 16/18
  through MCP, no escaped bug; 17 and 12 determined contracts, against 9 of 18 Dafny contracts
  that dafny-complete finds determined. Qwen 2.5 Coder 14B, run locally, writes no accepted
  solution, with or without the new syntax messages. Details in
  [bench/quod](https://github.com/quod-lang/quod/blob/main/bench/quod/README.md#three-trials-dafny-and-another-vendor).
