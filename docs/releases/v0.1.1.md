Quod 0.1.1: Quod as a tool for AI agents, and what a first user of 0.1.0 found.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first.

## New

- **`quod mcp`**, a Model Context Protocol server: an agent checks, builds and runs Quod programs
  through it, without a shell, and reads the language reference from it (`quod_check`,
  `quod_build`, `quod_run`, `quod_reference`). One line for Claude Code:
  `claude mcp add quod -- /path/to/quod mcp`; other clients, and a section to copy into
  AGENTS.md: [docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md). It speaks
  stdio and needs no environment variable (z3 is next to `quod`); a check through it has a time
  budget of 60 s by default (`budget` argument, or `quod mcp --budget N`).
  Haiku through the server wrote the six VerifBench tasks in 7 minutes instead of 47, all six
  verified with a determined contract.
- **`quod reference [SECTION]`** prints the language reference; the package also carries the
  specification (`doc/quod-0.1.md`).

## Fixed, from a first-user test of 0.1.0

- A `loose` relation whose parts each concern one result (`a < len(xs) && b < len(xs)`) relates
  nothing, and declares every result acceptable: it is now reported, like `loose (a, b) => true`.
- "The first index of a maximum" is recognised as determined: when the result is an index, the
  quantifiers of the `ensures` are given to the solver at both results.
- Functions whose `requires` asks for long sequences (`len(xs) == 9`) are now run on inputs that
  long; when no run breaks an obligation, the message names the branches no run took.
- With `--runtime-checks`, an `AssertionError` names the function, the property and the values.
- The undecided-completeness message says what to try.
