Quod 0.1.7: a hang that the held-out tasks found, and the result of those tasks.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first. The MCP server:
`claude mcp add quod -- /path/to/quod mcp`, or see
[docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md). `Quod.Build`, attached, is a NuGet package:
see [its README](https://github.com/quod-lang/quod/blob/main/packaging/Quod.Build/README.md).

## Fixed

- **`quod check` and `quod build` could hang, at random, on the same file.** After a check that timed out, reading a value of its partial model
  (`get-value`) has no time limit in z3: it could run for minutes and take gigabytes (23 GB in one case). Where that check stops depends on timing, so the same
  file answered in 3 s or hung. That read now has a limit of 5 s, after which the process is replaced and the search for a witness goes on without that value.
  On the six files that showed it, 12 of 48 commands went over 45 s before the fix. After it, none of 348 hung, and in the 288 that were timed the longest took 9 s.

## Known

- One `build` of those 348 commands, on the fixed compiler, stopped with exit code 3, an internal error while talking to z3. Its message was not kept and it did not come back in the
  next 300 commands, so its cause is not known. It fails loudly: nothing is built.
- If `quod` itself is killed during that read, its z3 can stay behind until it finishes.

## Measured

- [The held-out tasks](https://github.com/quod-lang/quod/blob/main/bench/runs/t7-heldout/report.md), 72 runs with Haiku on 0.1.6: **no accepted contract was found unsound in any arm, so soundness
  cannot tell the arms apart.** Giving Dafny a completeness check during writing changed nothing there (13 of 18 sound by execution, against 12; all the others undecided, and judged adequate).
  It doubled what the tool determines (8 of 18, against 4). The bench's two recorded escaped bugs were false: one was this hang, one a fault of the bench, both corrected and reported.

- Mutant bench: 57 of 64 mutants refuted, none unconfirmed or without a hint, the 7 survivors equivalent, none hung;
  quantified.quod 28 of 29. No verdict changed from 0.1.6.
