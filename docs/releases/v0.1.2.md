Quod 0.1.2: what a test of the MCP server of 0.1.1 found.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first. The MCP server:
`claude mcp add quod -- /path/to/quod mcp`, or see
[docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md).

## Fixed

- **The same verdict whatever the file holds.** `a == b * b * b && b > 2` was refuted alone in
  its file, and timed out next to a function on sequences: the sequence axioms are quantified, and
  with them z3 does not use its solver for nonlinear arithmetic. An obligation about integers and
  booleans only is now also put to a second z3 process that holds none of the program's axioms.
- **`quod mcp` keeps answering during a long check.** Tool calls run one at a time while the
  server keeps reading: `ping` and `tools/list` are answered at once, `notifications/cancelled`
  stops the call it names (z3 is killed, no response is sent), and a call that gives a
  `progressToken` gets a progress notification after each function checked.
- **The time budget is kept**: a check no longer overruns it by one time limit.
- **`quod_run` says what broke**: the clause and, for a postcondition, the value returned
  (`add(27, 3) returned 31, but postcondition (ensures #1) fails: result == a + b`).
- Wording: "an int"; the budget messages name the `budget` argument as well as `--budget`; the
  reference served to agents drops the vocabulary of the design documents.
