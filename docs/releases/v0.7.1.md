Quod 0.7.1: three fixes found by the first human trial of 0.7.0 (a prime-number program with a console prompt). Nothing else changes.

## Install

As for [0.1.0](https://github.com/quod-lang/quod/releases/tag/v0.1.0): download the package for
your system, unpack it, and run `quod` from that folder (z3 4.12.1 is inside). On macOS, run
`xattr -d com.apple.quarantine quod z3` in the folder first. The MCP server:
`claude mcp add quod -- /path/to/quod mcp`, or see
[docs/mcp.md](https://github.com/quod-lang/quod/blob/main/docs/mcp.md).

## Fixed

- **Python: a block left empty by erased proof steps.** `if x > 0 { lemma(x); assert ...; }` generated an `if` with no statement, which Python refuses to load (`IndentationError`) while `quod_build` said `built: true`. Such a block now holds `pass`.
- **A function that ends by calling itself after a `let`.** `let r = read_line(c); match r.1 { None => r.0, Some(_) => f(r.0) }` was not run as a loop, as the reference says it is, and overflowed the stack after a few hundred calls. A body of statements whose last one returns the tail call now runs as a loop, as a body of one expression already did.
- **A loop that reads the console was refused.** The pair `let r = console.read_line(d)` declared in the body counted as a console used and not handed back, though `d = r.0` handed it back, so no loop could read the console. What a turn declares is forgotten at its end.

## Measured

- Tests: 297, all passing; 3 were added, one per fix.
